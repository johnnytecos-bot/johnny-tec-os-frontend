How It Works

1. You send a message

A WhatsApp text, image, document, or video reaches Johnny.

2. AI processes it

Groq or Gemini reads it, checks memory, and decides how to respond.

3. Johnny replies or calls

A reply is sent on WhatsApp, and useful facts are saved for next time.

Service status is checked live against the backend. A service shows offline if its API key isn't set yet or it can't be reached.
